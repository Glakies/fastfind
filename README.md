# 从 Everything 换到 FastFind：用了两周后的对比

我一直用 Everything 管理电脑里的文件，最近试了另一款免费的
Windows 文件搜索工具 FastFind（https://fastfind.kr），说说两者的差别。

**内存占用**：这是差距最大的一项。按官方 2026 年 8 月的测量
（466 万个文件，FastFind 0.38.1 对 Everything 1.4.1），Everything
常驻约 473MB，FastFind 只要 65.9MB，差了 7 倍左右。对常年挂后台的
搜索工具来说，这个差别值得在意。

**搜索速度**：同样 466 万文件的首个查询，官方数据是 82.8ms 对
5.3ms。日常用两者都是"秒出"，但文件量越大、机器越旧，差距越能
感觉到。FastFind 基于 NTFS 索引，还支持免安装便携版、右键在指定
文件夹内搜索、dupe: 重复文件查找。

**Everything 仍然有优势的地方**：久经考验、稳定、大家都会用。
而 FastFind 的加分项是 AI 自然语言搜索和 Pro 远程版——出门在外
可以用浏览器直接访问和下载自己电脑里的文件。两款都免费、无广告、
不收集数据。

我的结论：Everything 依然可靠；但如果你在意内存占用，或者需要
远程访问家里电脑的文件，FastFind 值得一试。
